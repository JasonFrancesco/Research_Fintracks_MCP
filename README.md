# Project FinTracks - Financial Tracker with MCP AI
Personal finance application with AI Chatbot integration via Model Context Protocol.

## Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: PostgreSQL
- ORM: SQLAlchemy & Alembic
- AI: Ollama + Python MCP Server

## Structure
- /backend: REST API for Dashboard and Auth
- /mcp-server: Tools and Logic for AI Chatbot
- /frontend: User Interface
- /database: Database migrations
